# 衡绩离线发布与启动速度

本项目提供两种 Windows x64 免安装成品，都已包含 Electron 运行时，目标电脑无需安装 Node.js、Electron 或浏览器。首次运行时 Windows 安全扫描可能增加等待时间。Windows 10/11 x64 为目标平台；仍需在一台没有开发环境的目标电脑上验收。

| 成品 | 使用方法 | 数据保存 | 启动特点 |
| --- | --- | --- | --- |
| 单文件 `.exe` | 复制一个文件，双击运行 | 首次新建工作区时自主选择 `.hengji` 路径 | 每次运行都重新解压 Electron 到系统临时目录，实测约 23 秒 |
| 快速启动文件夹 | 解压一次后，双击文件夹内的“衡绩员工绩点考核系统.exe” | 同上 | 解压后再次启动约 0.5–0.9 秒；首次启动可能受安全扫描影响 |

测试机实测：原单文件约 19.5 秒；ZIP 单文件约 24.6 秒、110 MB；无压缩单文件首次约 22.6 秒、再次约 11.3 秒、270 MB；最终单文件 69.3 MB、窗口可见约 23.1 秒；最终免安装文件夹首次约 11.8 秒、再次约 0.86 秒。不同电脑和杀毒软件的结果会变化。最终保留压缩单文件以控制分享体积，同时提供免安装文件夹版以满足日常快速启动。

工作区内容不会写入 EXE。建议在非系统盘自建 `衡绩工作区` 文件夹，放置 `.hengji` 及自动生成的 `.backup`；换电脑时复制这两个文件，并记住工作区口令。共享员工与专业组请使用软件内“导出共享基础库”，所得 `.hjbase` 不包含项目、月度工作内容和绩点。不要把 `.hengji`、`.backup`、全量灾备或绩点 CSV 发给无权限人员。

当前离线版以工作区口令保护整个工作区。知道口令并打开完整工作区的人可以查看其中所有绩点；它尚未实现独立身份认证或真正的按项目负责人隔离。涉及多人分级访问时，应只把完整工作区交给授权管理员，其他人仅接收 `.hjbase`。发布签名还需要单位代码签名证书，步骤见《代码签名与发布》。
